# LichTV 工作流测试附件

完整报告位于压缩包中的 `docs/inference/lichtv_workflow_benchmark_2026-11-15.md`。

- `summary.csv`：53项工作流的耗时、等效GPU费用、实际输出和最终结果，Excel可直接打开。
- `model-configs.csv`：模板引用的模型、编码器、VAE、LoRA及加载节点。
- `results.json`：环境、逐项后端配置、参数覆盖、全部59次尝试及错误记录。
- `results.csv`：适合程序处理的完整配置与主结果。
- `media-verification.json`：71个生成媒体文件的完整解码核验结果。
- `samples/`：三段可离线播放的首页H3样片。

本轮最终51项成功、2项失败。请求等效费用合计6.7265元；测试观察窗口按3元/小时折合32.5479元，其中包含服务中断后的等待。两项金额采用不同口径，不要相加；实际扣费以平台账单为准。

每种配置只测一次，结果不代表画质排名或稳定性结论。线性折合一分钟的费用不包含重抽、剪辑、拼接及空闲。封装节点的内部配置未暴露，报告明确保留未知项。
