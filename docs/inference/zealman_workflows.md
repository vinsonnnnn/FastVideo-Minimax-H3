# Zealman 镜像：50 个工作流怎么选

面向使用单卡 RTX 5090 制作 AI 短剧的用户。本文根据当前服务器面板的注册清单和实际工作流 JSON 解释每一项，供你在“API生成”、快捷生成或画布中选模板。

核对日期：2026-11-14。清单来源为面板的只读接口 `GET /api/workflow/list` 与 `GET /api/workflow/config/{id}`，不是仅按工作流文件名猜测。共50项：H3视频18项、图像与提示词15项、LTX视频5项、Wan视频4项、动作迁移3项、语音1项、视频后期3项、接口测试1项。没有逐项运行GPU推理，因此本文不提供速度、画质排名或显存可运行保证。

## 先理解工作流

工作流是一套预先连接好的步骤，例如“加载模型 → 读取参考图/声音 → 采样 → 解码 → 放大 → 保存”。50个工作流不等于50种模型：同一模型换输入、LoRA、采样器、加速或放大方式，就能成为另一项。

- `API-` 表示模板可被面板接口调用，不表示一定调用外部付费模型。可见的H3、Wan、LTX、Qwen等生成图主要通过本机ComfyUI节点执行。封装节点、LLM或语音节点的内部网络依赖未逐一审计。
- `U06/U08/U30/U32` 是作者编号；`V1/V2/V5/V9` 多为工作流修订号，不是H3官方型号、模型参数量或质量排名。
- “9图3音”表示入口上限，不要求每次都填满，也不表示9个角色能自动保持身份或3段音频能自动组成对白时间轴。
- “参考图生视频”利用角色、服装、场景等条件；“图生视频”通常更侧重给定画面；“首尾帧”明确提供起止画面；“动作迁移”利用已有动作视频。不要把这些输入条件当作同一功能。
- 本文出现的模型名称取自模板配置，未核验模型发布方、命名真实性或全部文件的可读性。加载器出现某模型/LoRA不等于该分支一定会执行，旁路和开关也影响结果。

## 为短剧原型选择一条最短路线

先验证一个镜头，再逐步增加素材和后处理。以下是按功能匹配选择的起点，不是已实测的性能推荐。

1. **先做接口连通**：Z-连通测试，确认上传、提交任务和取回文件。
2. **准备人物、场景**：C16或B18出图；已有角色图可用B13补角度、D14做分镜，或B20编辑。
3. **生成第一个H3镜头**：U06-9图版API-V5，先只给一张角色图，选择短时长和较小尺寸。当前配置有8步采样；完成后记录实际耗时、峰值显存和声音输出。
4. **做人物对白**：N2先生成语音，再用U11尝试图像+语音对口型；也可用LTX的H31/J11做对照。
5. **增加参考素材**：确实需要参考音频时选U06-9图3音频-V5；需要参考视频时再比较U17、U07-A或封装版U00。不要一开始填满全部入口。
6. **提升成片观感**：先比较U08/U22/U30等二采方案；已有成片可用M20做二倍超分、Z10补帧。每次只加一项，方便判断效果与开销。

多镜头短剧还需要脚本拆分、角色资产管理、镜头审核、剪辑拼接和对白/字幕管理。模板覆盖了其中不少生成环节，但某个模板名带“短剧”或“制造机”并不代表会自动完成这些环节。

## 单卡5090上如何判断是否适合

当前卡约32GB显存。先看实际启用的权重精度、参考图尺寸、视频时长、输出分辨率、是否二采/超分以及模型卸载策略；不能只看模板名称。B20配置中有BF16大组件，P17明确标注48G专用，这两项尤其不能当作32GB卡的已验证方案。

H3模板中多处可见INT8主模型与NVFP4 AWQ或INT8文本编码器；“文本编码器为NVFP4”不等于“H3主模型就是FastH3 Omni QAD NVFP4”。本次列出的H3工作流主要配置fl2va/ref2va、hybrid、Singularity及Turbo/社区组合。面板的工作流集合和此前专用Omni导演台镜像不是同一套配置。

模型清单中的公共仓链接、节点已注册、模板能打开，分别只能说明索引/安装/配置存在。确认可用仍需提交任务并检查生成文件。本次检查未修改远端设置、安装依赖或触发视频生成。
